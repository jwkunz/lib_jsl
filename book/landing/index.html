Looking for something specific? The book's catalogue of algorithms lists everything the library implements, with a link to the entry that explains each one.

Get started

cargo add lib_jsl            # everything, re-exported by domain
cargo add lib_jsl_linalg     # or a single domain crate
use lib_jsl::integration::gaussian_quadrature::GaussLegendreEngine;

Each domain crate also works on its own. The book's API conventions entry describes the shared error type, result types and the stability policy.
